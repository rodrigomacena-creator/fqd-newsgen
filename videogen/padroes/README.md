# Catálogo de padrões de vídeo

Estes são os estilos aprendidos a partir dos vídeos de referência. Para produzir um vídeo, escolha um padrão pelo **nome** ou pelo **id** (ex.: "faz no padrão 2" ou `estudio-serif-cinematico`). O pipeline lê o front matter YAML do arquivo do padrão escolhido (formato, paleta, fontes, ritmo, música, CTA) e usa a seção "Dicas de geração" para montar os prompts.

## Como adicionar um padrão novo
1. Salvar o vídeo de referência em `referencias/padrao-NN-referencia.mp4`.
2. Criar `NN-<id>.md` com o mesmo front matter (id, nome, formato, paleta, fontes, cena_s, transicao, legenda, musica, cta) e as mesmas seções.
3. Adicionar uma linha nas tabelas acima.
